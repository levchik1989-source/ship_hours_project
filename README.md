# Ship Hours

Commercial Flutter + Material 3 work hours tracker for seafarers.

## Build

```bash
flutter pub get
flutter run
```

## Status

This archive contains the integrated source code for the Flutter layer, assets, localization, Hive persistence, calendar, day editor, statistics and settings screens.

To create a full platform project, run `flutter create .` inside this folder if Android/iOS folders are missing, then run `flutter pub get`.
